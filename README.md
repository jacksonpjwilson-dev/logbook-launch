# Logbook launch page

The promo page for the new Logbook widget home. It's a static site served by GitHub Pages.

- `index.html`, `styles.css`, `app.js`: the page
- `shots/`: 1179×2556 (393×852 @3x) captures of the live preview, taken with sample data that's seeded only in the capture browser
- `icon.svg`, `icon-*.png`: the app icon
- `styles/`: an earlier style-exploration gallery (not linked from the page)
